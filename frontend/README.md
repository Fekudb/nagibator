# Нагибатор диванных критиков: детектор токсичных комментариев (веб-интерфейс)

Веб-интерфейс для системы определения токсичности комментариев на форуме МТУСИ.
Отправляет текст на ML-бэкенд и отображает результат с цветовым индикатором (красный — токсично, зелёный — нейтрально).

## Установка

```bash
cd frontend
python3 -m venv .venv
source .venv/bin/activate
make install
```

## Запуск

Перед запуском убедитесь, что ML-бэкенд работает на порту 8000 (см. README в папке `ml_api/`).

```bash
make run
```

Интерфейс будет доступен по адресу: http://localhost:5001

## Запуск через Docker

```bash
make docker-build
make docker-run
```

Или оба сервиса одной командой из корневой папки:

```bash
docker compose up
```

## Тестирование

```bash
make test
```

Тесты используют моки API-вызовов — бэкенд для запуска тестов не нужен.

## Линтер

```bash
make lint          # проверка
make lint-fix      # автоисправление
```

## Makefile

| Команда            | Действие                                  |
|--------------------|-------------------------------------------|
| `make run`         | Запуск Flask-приложения                   |
| `make install`     | Установка зависимостей                    |
| `make lint`        | Проверка кода (ruff)                      |
| `make lint-fix`    | Автоисправление (ruff)                    |
| `make test`        | Запуск тестов (pytest)                    |
| `make docker-build`| Сборка Docker-образа                      |
| `make docker-run`  | Запуск контейнера                         |
| `make clean`       | Удаление кэшей (__pycache__, .pyc и т.д.) |
